# ai-check-bot

Telegram-бот-диспетчер задач разработки (аудит/чек, фичи, фиксы,
рефакторинг) по нескольким проектам сразу, с поддержкой нескольких
ИИ-провайдеров (Claude, Codex, Cursor, локальная LLM) и интеграцией с
GitHub.

## Статус

Ранняя стадия, готовится к open source. ТЗ и схемы архитектуры готовы,
код — в разработке.

## Начни отсюда

**[docs/PROJECT_SPEC.md](docs/PROJECT_SPEC.md)** — полное техническое
задание, источник правды по продукту. Именно этот файл нужен агенту,
который будет писать код.

## Архитектура

- [Карта меню бота](docs/architecture/ui-map.mermaid)
- [Бэкенд-архитектура](docs/architecture/backend-architecture.mermaid)

> Эти схемы описывают Claude-only режим Чека — актуальны как основа
> протокола ЧЕК, но не отражают ещё мульти-провайдерность и новые типы
> задач (Фича/Фикс/Рефакторинг) из PROJECT_SPEC.md. Обновятся по мере
> кодинга.

## Ключевые принципы

- Источник истины по багам — `chek_open.md` / `chek_never.md` /
  `chek_later.md` в каждом репо, бот только кэширует для UI
- Коммит всегда подтверждает человек — независимо от провайдера
- Автопроверка по квоте — выключена по умолчанию
- Удаление репозиториев и истории коммитов исключено на уровне кода,
  не только UI

## Установка

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # заполнить токены
```
